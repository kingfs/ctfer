#
# NOTE: chepy is NOT listed here. It pins pyOpenSSL 23.2.0 (cryptography<42) or
# pyjwt 1.7.1, so installing it into the main venv downgrades cryptography and

# volatile dependency trees, and a resolver hiccup here must not break the core
# pwn/crypto stack (pwntools, angr, z3). Each line is installed separately and
# warn-only, so one bad pin cannot take the others down with it.
